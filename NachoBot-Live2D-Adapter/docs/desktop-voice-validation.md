# 桌宠语音验证

2026-10-02，Windows、Hiyori 示例模型、PyGame 实际音频设备。
PR 基于 `upstream/dev` 的 `7ebb8097`；新增或修改的源码均在 Live2D 适配器内。

测试句：`你好，我是日和。我们慢慢说，保证每一句都能听清。`

| 项目 | 实测 |
| --- | --- |
| 快速神经语音首次播放 | 1.45 秒（其他运行约 1.92–2.44 秒） |
| 完整音频时长 | 6.43 秒 |
| 中文字数 / 音频秒数 | 20 / 6.43，约 3.11 字/秒 |
| 句间额外等待 | 最大约 0.03 秒 |
| 实际口型 | 播放时运动，停止后关闭 |
| Core 请求到文字回复 | 4.05 秒 |
| 文字回复到实际语音播放 | 1.88 秒 |
| 闭嘴到音频停止 | 0.03 秒，后续 2 秒未重播 |

上述播放时间来自真实 renderer 的 mixer channel 状态，而非 HTTP 端口或合成请求完成时间。
快速模式使用 `zh-CN-XiaoxiaoNeural`、`-10%` 语速，需要网络；数值会随网络和模型服务变化。
CPU Whisper base 的自由识别结果为“你好，我是日何我们慢慢说，保证每一句都能听清”；
人物名字“日和”存在同音误识别，其余测试句内容完整。

当前本机 Vox 基线首 PCM 约 1.55 秒，但生成 6.4 秒语音总耗时约 36.46 秒。
减至 3 个推理步后首 PCM 约 0.89 秒，总耗时仍约 20.54 秒。
因此快速模式提供可选的另一音源，不能把这些结果解释为 Vox 模型性能已修复。
本机音色模式保留新版及旧版 Multimodal PCM 接口，按实际格式重采样，不通过加速播放减少等待。

回归命令：`uv run python -m unittest discover -s tests -q`，78 项，77 通过、1 项跳过。
新增测试覆盖真实 WebSocket 消息关联、迟到/其他用户回复过滤、静音后的迟到音频、
HTTP PCM 格式及边界、连接关闭时完成音频排空和未完成音频取消；原有测试覆盖重采样时长、结尾排空、流取消、窗口和模型适配。
PowerShell 启动脚本解析通过；Python 静态未定义名称检查通过。
