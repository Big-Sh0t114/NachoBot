# Attribution and scope

This native NachoBot integration adapts the self-character recognition concept
from [MaiSelfPlugin](https://github.com/SengokuCola/MaiSelfPlugin), by
SengokuCola, under GPL-3.0-or-later. It is rewritten for NachoBot's native V1
plugin and tool interfaces and uses the separately maintained
`plugins.mai_recog_self.backend` backend.

No personal images, source labels, experiment results, or trained identity
models are included. Runtime data is stored in the configured plugin data root.
This adaptation has no WebUI, upload API, or chat-driven training behavior.
