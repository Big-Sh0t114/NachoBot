# 本地画作插件（Artwork）

用户明确提出“发张图 / 看看画作”等请求时，Planner 会结合当前请求和最近聊天记录，从本地画夹中挑选一张作品。仅讨论绘画或表达“我想画画”不会触发。

## 配置

```toml
[components]
enable_send_artwork = true

[artwork]
directory = "artwork"
allowed_extensions = [".png", ".jpg", ".jpeg", ".gif", ".webp"]

[access_control]
discord_artwork_whitelist = ["Discord用户ID"]
```

相对路径以 `NachoBot` 运行目录解析。Discord 群聊不发送画作，Discord 私聊仅对白名单用户开放；其他平台按各自图片发送能力处理。

## 选图方式

插件每次执行都会重新读取画夹目录和支持的扩展名，因此新增、删除或替换图片会在下一次请求时生效。选图时会优先用已保存的画面描述缩小候选范围；没有可匹配的描述时，会从当前图片中随机抽取不超过 15 张作为候选，其中拼图最多展示 10 张，额外候选用于跳过损坏文件。最终发送始终从拼图实际返回的编号映射中取图。

视觉模型会根据带编号的拼图选择图片，并可在同一次响应中为可辨认的候选补充简短描述。描述以图片字节的 SHA-256 为键，保存在 `NachoBot/data/artwork_descriptions/`；文件内容变化后会使用新的键，旧描述不会套用到替换后的图片。冷缓存时不会逐张调用视觉模型；尚无描述的候选会明确标记为“仅文件名提示”。

如果视觉选择不可用或返回无效编号，插件会让 `utils_small` 根据当前请求、最近记录和候选描述进行文字选图。两种模型选择都不可用时，会在当前有界且可读取的候选中随机发送一张。图片读取或发送失败时会静默返回失败，不发送描述或其他文字，也不记录动作成功。
