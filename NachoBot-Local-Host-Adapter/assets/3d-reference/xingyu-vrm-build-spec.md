# 星语主播 · VRM 建模规格 v1

参考图：`xingyu-vrm-front-reference-v1.png`

## 角色定位

- 原创成年女性虚拟主播；温暖、自信、带一点软萌感。
- 不基于、不模仿任何真实人物或现有 IP 角色。
- 最终用途：抖音直播画面中的全身 3D 角色，支持说话表情与舞蹈动作。

## VRoid Studio 制作目标

- 体型：成年女性，约 7.5 头身，健康自然比例；避免幼态比例。
- 脸部：明亮蓝色眼睛、柔和笑脸、自然鼻唇；保留眨眼与张口表情。
- 发型：深海军蓝长发，带少量钴蓝高光；前刘海偏右；开启头发摇摆。
- 饰品：左右各一个小型星形耳饰。
- 上装：深蓝短夹克，黑色高领内搭；衣料应方便手臂大幅抬起。
- 下装：深蓝不对称半身裙，内层钴蓝星空纹；黑色不透明连裤袜、深蓝短靴。
- 材质：干净的 PBR/卡通写实混合材质；直播中在暖色灯光下仍要保持面部清楚。

## 导出要求

1. 导出 **VRM 1.0**，保持完整全身骨骼、手指骨骼、表情 BlendShape 与发丝 Spring Bone。
2. 使用原创素材，并在导出许可中允许直播展示；不要包含第三方受限纹理或角色资产。
3. 文件名固定为 `xingyu-host-v1.vrm`，后续放入 `NachoBot-Local-Host-Adapter/models/`。
4. 舞蹈不内嵌在角色里：后续另接 `.vrma` 动作文件，可独立切换软萌、活力、优雅三种舞蹈。

## 直播镜头建议

- 竖屏时将完整人物置于右侧，脚底保留少量边距；左侧预留字幕与话题。
- 摄像机高度在锁骨附近，焦距约 50mm 等效；背景使用现有暖色直播间。
- 初始状态：轻微呼吸与眨眼；说话时口型、头部和肩膀轻微联动；只有触发舞蹈时才播放全身动作。
