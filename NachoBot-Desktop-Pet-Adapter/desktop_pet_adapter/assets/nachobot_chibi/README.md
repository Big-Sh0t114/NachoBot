# NachoBot chibi animation assets

Generated for this project with the built-in image_gen tool on 2026-11-02, using the user's Nacho-v2 character reference board and a render of the existing local NachoBot Live2D model. The master preserves the reference character identity; these are new sprite illustrations, not reused Live2D motions.

- `character-reference.png`: detailed full-body character master.
- `sprites.png`: corrected 24-frame atlas: idle, walk, climb, fall, drag, react; four frames each.
- `sprites-left.png`: independently redrawn leftward walk/climb variants, selected by `left_atlas` and `left_states`; never generated by runtime mirroring.
- `manifest.json`: exact frame rectangles and playback rates. The generated row spacing is not a uniform grid. Use the explicit rectangles rather than blindly slicing into 256-pixel rows.
- The optional per-state `face_rects` in `manifest.json` are tile-local inset rectangles covering the robot's red expression. Sprite runtime renders its aggregate input count there after a counted keyboard press or mouse click, then restores the ordinary robot expression five seconds after the last count increment. Mouse movement does not restart this timer or wake the numeric display. A held key counts once on its initial press; automatic key repeats do not increment the count or restart the timer. Releasing and pressing again creates a new count. Counts remain exact and persistent.

## Animated ordinary LED expressions

When the numeric display is inactive, a procedural pixel-LED layer cycles through neutral, smile, curious, sleepy and focused expressions in a ten-second loop, with 150 ms blinks. Drag, fall and react use matching clenched, surprised and excited faces. Both directional atlases use their own selected face rectangles; the shell artwork and PNG files are unchanged by this expression feature.

The counter has display priority after a new counted key press or mouse click. After five seconds without a new count increment, the ordinary cycle starts again. Mouse motion and held-key autorepeat neither wake the numbers nor reset the cycle. A sprite without face metadata keeps its original artwork.
